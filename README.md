# Mateo Úsuga Álvarez

Se desarrolló un proyecto en Kotlin donde se implementaron ejercicios prácticos para aprender los fundamentos del lenguaje. Se trabajó con variables, manejo de valores nulos (Null Safety), estructuras condicionales, ciclos, funciones y colecciones. Además, se aplicaron conceptos como parámetros por defecto, funciones de una sola línea y extensiones, organizando todo en archivos estructurados dentro de un mismo proyecto.
